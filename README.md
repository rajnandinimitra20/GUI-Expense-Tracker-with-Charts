# Expense Tracker

A Python GUI application to track daily expenses.  
Features:
- Add expenses with amount, category, description, and date
- View all expenses in a table
- See a pie chart of expenses by category
- CSV storage ensures data is persistent

# Technologies Used:
 Python, Tkinter, Matplotlib, CSV  

# How to Run:
1. Install dependencies: `pip install matplotlib`
2. Run the script: `python GUI_Expensetracker.py`
